# Ranet Outcome Report 사용 안내

면담·보고회·회의 녹음과 메모·자료를 넣으면 출장결과보고서 한글 파일(.hwpx)을 만들어 주는 프로그램입니다.
녹음 전사는 내 PC 에서 무료로 하고, 보고서 초안은 각자의 Claude 또는 Codex(ChatGPT) 계정으로 씁니다.

## 1. 받기

1. https://github.com/JM4695/ranet-outcome-report-releases/releases/latest 에서 `RanetOutcomeReport.exe` 를 받습니다.
2. 바탕화면 등 원하는 곳에 두고 실행합니다. 설치 프로그램은 따로 없습니다.
   - 서명되지 않은 프로그램이라 처음에 «Windows의 PC 보호» 창이 뜰 수 있습니다. 회사에서 받은 파일이 맞으면 «추가 정보 → 실행» 을 누릅니다.

## 2. 처음 실행 — 환경 점검·설치

처음 실행하면 «환경 점검» 창이 뜹니다. 보고서를 만드는 데 필요한 부품을 확인하고 없는 것을 설치합니다.

| 항목 | 설명 |
|---|---|
| 기본 구성 | 프로그램 엔진·Python. 꼭 필요 |
| ffmpeg | 녹음 파일을 읽는 도구. 꼭 필요 |
| GPU 가속 | NVIDIA 그래픽카드가 있을 때만. 있으면 전사가 몇 배 빠름 |
| 사진·슬라이드 글자 인식 | 사진으로 찍은 메모·슬라이드를 읽을 때 |
| Whisper 모델 | 전사 모델(GPU PC 약 3GB, 그 밖 약 1.6GB). 미리 받아 두면 첫 전사가 빠름 |

[기본 구성 설치]를 누르면 필수 부품을 설치합니다. GPU·사진 인식·모델 미리 받기는 ‘선택 기능 추가 설치’에서 필요할 때 고릅니다.
설치 위치는 `%LOCALAPPDATA%\RanetOutcomeReport`, 작업 자료는 `문서\RanetOutcomeReport_Workspace` 입니다.

전사 시간은 PC·모델에 따라 다릅니다. 이 개발 PC의 61.8분 녹음 실측은 CPU turbo 약 25분, CPU large-v3 약 52분이었습니다. 모델을 처음 받는 시간은 별도입니다.

## 3. AI 연결 — 각자 자기 계정으로

보고서 초안은 Claude Code 또는 Codex 가 씁니다. **계정은 각자 것을 쓰고 공유하지 않습니다.**

1. 환경 점검 창 «AI 연결»에서 쓰려는 도구를 설치합니다.
2. 프로그램의 [설정 → AI 연결]에서 Claude 또는 Codex의 계정 연결을 실행하고 브라우저에서 자기 계정으로 로그인합니다.
3. 브라우저 뒤 인증 코드가 필요한 경우 연결 창의 접힌 인증 입력칸을 사용합니다. 연결 상태를 다시 확인하세요. 설치됨만으로 로그인된 것은 아닙니다.
4. 연결이 끝나지 않으면 연결 창을 닫고 PowerShell에서 `claude` 또는 `codex`로 직접 로그인한 뒤 앱에서 연결 상태를 다시 확인할 수 있습니다.

사용하는 AI 계정의 이용 조건과 사용량 한도가 적용됩니다.

## 4. 첫 보고서

1. 사업 목록의 [새 사업]으로 사업을 만듭니다. 사업 공통 자료에 과업지시서·사업계획서를 넣어 두면 사업명·용어를 참고합니다.
2. [새 보고서]에서 날짜와 제목을 입력합니다. 최근 보고서에서는 이름·날짜로 검색할 수 있습니다.
3. **자료·개요**에서 녹음·클로바 전사본·메모·발표자료·사진을 종류별 칸에 넣습니다. 각 칸에서 들어간 파일을 확인합니다. 일시·장소·참석자·목적도 적습니다.
4. **[보고서 작성·이어서 보기]**를 누릅니다. 필요한 자료 읽기·전사와 AI 초안 작성을 이어서 진행합니다. 클로바 전사본은 녹음과 같은 이름으로 넣으면 대조에 도움이 됩니다. 자료를 추가했다면 [새 자료 읽기] 후 AI에게 반영을 요청합니다.
5. **보고서 작성**에서 실제 한글 쪽 모습을 확대해 봅니다(한글 설치 필요). 옆 AI 대화에 ‘두 번째 안건을 빼고 결정 사항의 담당자를 바꿔줘’처럼 요청합니다. 진행 상황·AI 답변·수정 제안 비교를 확인하고 적용하거나 버립니다. 미적용 제안이 있으면 먼저 정리합니다.
6. **직접 고치기**: [문단별 편집]으로 글자·글꼴·크기·굵기·글머리·정렬·문단 위아래 간격·들여쓰기를 고칩니다. 저장 뒤 실제 쪽 미리보기로 확인합니다. 크게 보기에서도 문단 편집으로 이어갈 수 있습니다. 표·구조를 직접 고치는 고급 기능은 초안 편집을 사용합니다.
7. 화자가 불분명하면 **실제 발언과 시각을 보고** [발언으로 화자 확인]에서 이름을 적습니다. 해당 시각 녹음을 들을 수 있습니다. 모르면 추정하지 않고 ‘지금은 알 수 없음’을 선택합니다. 확인한 이름은 AI에 발언자 표기만 반영하도록 요청할 수 있습니다.
8. 이름·수치의 근거가 필요할 때 **원자료 대조**를 엽니다. 읽은 텍스트는 자동 선택하고 전사 교정본을 직접 고칠 수 있습니다. 전사 시각·녹음 타임라인으로 이동합니다. 원본 파일과 교정본은 구분합니다. 모든 자료를 매번 수동 승인할 필요는 없습니다.
9. **[한글 파일 만들기]**로 검토한 내용을 새 HWPX로 저장합니다. 확인이 필요한 내용이 남아 있으면 안내를 읽고 결정합니다. 오류가 나면 상세 기록의 원인을 확인하며 이전 파일은 유지됩니다.
10. **한글 파일·이력**에서 최신 파일·이전 버전을 엽니다. 기존 한글에서 고친 서식을 그대로 유지하며 글자만 바꾸려면 [기존 한글 서식 유지하며 고치기]를 사용합니다. 서식·표·사진 보존 검사 후 새 버전으로만 저장합니다. 옛 판을 선택하면 그 뒤 판의 변경은 포함되지 않습니다. 이름을 바꾼 파일이 미등록으로 표시되면 [보고서로 등록]으로 지정합니다. 참고용 파일은 [참고 파일로 제외]로 구분합니다.
11. 이전 초안으로 되돌릴 때는 [이전 초안으로]를 사용합니다. 현재 내용도 백업하며 기존 HWPX는 바꾸지 않습니다. [보낸 판 보관]은 제출·발송한 파일의 별도 사본과 메모를 남깁니다. 파일 전송 기능은 아닙니다. 보관 사본은 읽기 전용으로 보호하며 열 때는 작업 사본을 엽니다.
12. 반복되는 수정은 대화의 [규칙 후보로] 또는 자동 후보에서 정리합니다. ‘이 보고서/이 사업/모든 보고서’ 범위와 문구를 확인해 적용합니다. 후보만으로 자동 적용되지 않습니다. 금지·필수 문구는 최종 한글 파일에서도 검사할 수 있습니다.

자료·개요·양식이 바뀌면 검토 기준도 달라집니다. 기존 초안을 쓰려면 내용을 대조하고 [기존 초안 다시 등록]으로 이어갑니다. 한글에서 직접 고친 내용을 초안에 반영하려면 [한글 수정본 불러오기]를 사용합니다. 한글 원본은 덮어쓰지 않습니다.

사업·보고서 삭제는 복구 가능한 임시 보관으로 이동합니다. 보관함에서 복원하거나 비울 수 있으며, 영구 삭제 안내를 확인한 뒤 비우세요.

## 5. 양식 바꾸기

[양식] 에서 작성 규칙·번호 형식·제목 앞 빈 줄·표 번호·표지 기관명 등을 바꿉니다.
문단 스타일은 기존 항목도 편집할 수 있고 번호 형식은 기본값에 고정되지 않습니다.
오른쪽 미리보기가 바로 바뀌고, [한글로 정확히 보기] 는 지금 값으로 견본 보고서를 만들어 한글로 엽니다(내 설정·작업은 그대로).
표지·스타일은 [한글에서 템플릿 열기] 로 직접 고칩니다. 고치기 전 원본은 자동으로 백업됩니다.

## 6. 업데이트

프로그램을 열 때 새 버전을 확인해 받습니다. [설정 → 지금 업데이트 확인] 으로 직접 확인할 수도 있습니다.
내가 고친 작성 규칙·표준템플릿과 작업 자료는 업데이트해도 그대로 남습니다
(새 기본값은 옆에 `.새기본값` 파일로 둡니다).

## 문제가 생기면

- [설정 → 환경 점검·설치 열기] 로 빠진 부품을 다시 설치합니다.
- 작업 화면 «상세 진행 기록»의 마지막 줄을 캡처해 담당자에게 보내 주세요. 이전 실패·중단 기록은 다시 열어도 확인할 수 있습니다.
- 앱을 닫으면 실행 중인 작업도 멈춥니다. 초안이 다른 프로그램에서 바뀌었다는 안내가 나오면 현재 편집 내용을 따로 복사해 보관한 뒤 작업을 다시 여세요.
