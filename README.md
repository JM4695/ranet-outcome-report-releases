# Ranet Outcome Report 사용 안내

면담·보고회·회의 녹음과 메모·자료를 넣으면 출장결과보고서 한글 파일(.hwpx)을 만들어 주는 프로그램입니다.
녹음 전사는 내 PC 에서 무료로 하고, 보고서 초안은 각자의 Claude 또는 Codex(ChatGPT) 계정으로 씁니다.

## 1. 받기

1. https://github.com/JM4695/ranet-outcome-report-releases/releases/latest 에서 실행파일을 받습니다. GitHub에는 `Ranet Outcome Report.exe`, 점으로 구분된 이름, 또는 이전 호환 이름으로 표시될 수 있습니다. 저장할 때 `Ranet Outcome Report.exe`로 이름을 맞추면 됩니다.
2. 바탕화면 등 원하는 곳에 두고 실행합니다. 설치 프로그램은 따로 없습니다.
   - 서명되지 않은 프로그램이라 처음에 "Windows의 PC 보호" 창이 뜰 수 있습니다. 회사에서 받은 파일이 맞으면 "추가 정보 → 실행" 을 누릅니다.

## 2. 처음 실행 — 환경 점검·설치

처음 실행하면 "환경 점검" 창이 뜹니다. 보고서를 만드는 데 필요한 부품을 확인하고 없는 것을 설치합니다.

| 항목 | 설명 |
|---|---|
| 기본 구성 | 프로그램 엔진·Python. 꼭 필요 |
| ffmpeg | 녹음 파일을 읽는 도구. 꼭 필요 |
| GPU 가속 | NVIDIA 그래픽카드가 있을 때만. 있으면 전사가 몇 배 빠름 |
| 사진·슬라이드 글자 인식 | 사진으로 찍은 메모·슬라이드를 읽을 때 |
| Whisper 모델 | 전사 모델(GPU PC 약 3GB, 그 밖 약 1.6GB). 미리 받아 두면 첫 전사가 빠름 |

[기본 구성 설치]를 누르면 필수 부품을 설치합니다. GPU·사진 인식·모델 미리 받기는 ‘선택 기능 추가 설치’에서 필요할 때 고릅니다.
설치 위치는 `%LOCALAPPDATA%\Ranet Outcome Report`, 작업 자료는 `문서\Ranet Outcome Report_Workspace` 입니다.

전사 시간은 PC·모델에 따라 다릅니다. 이 개발 PC의 61.8분 녹음 실측은 CPU turbo 약 25분, CPU large-v3 약 52분이었습니다. 모델을 처음 받는 시간은 별도입니다.

## 3. AI 연결 — 각자 자기 계정으로

보고서 초안은 Claude Code 또는 Codex 가 씁니다. **계정은 각자 것을 쓰고 공유하지 않습니다.**

1. 환경 점검 창 "AI 연결"에서 쓰려는 도구를 설치합니다.
2. 프로그램의 [설정 → AI 연결]에서 Claude 또는 Codex의 계정 연결을 실행하고 브라우저에서 자기 계정으로 로그인합니다.
3. 브라우저 뒤 인증 코드가 필요한 경우 연결 창의 접힌 인증 입력칸을 사용합니다. 연결 상태를 다시 확인하세요. 설치됨만으로 로그인된 것은 아닙니다.
4. 연결이 끝나지 않으면 연결 창을 닫고 PowerShell에서 `claude` 또는 `codex`로 직접 로그인한 뒤 앱에서 연결 상태를 다시 확인할 수 있습니다.

사용하는 AI 계정의 이용 조건과 사용량 한도가 적용됩니다.

## 4. 첫 보고서

작업 화면은 **자료 넣기 → 만들기 → 결과** 3단계입니다.

1. 사업 목록의 [새 사업]으로 사업을 만듭니다. 사업 공통 자료에 과업지시서·사업계획서를 넣어 두면 사업명·용어를 참고합니다.
2. [새 보고서]에서 날짜와 제목을 입력합니다.
3. **자료 넣기**: 녹음·클로바 전사본·메모·사진·문서를 오른쪽 칸에 한꺼번에 놓습니다. 종류는 자동으로 나누고, 못 읽는 파일만 따로 알려 줍니다.
   - 한 보고서에 여러 만남을 담을 수 있습니다(예: 4일 김 교수 면담 + 6일 세 교수 면담). 녹음 파일 이름에 사람 이름(예: 김종진.m4a)을 쓰면 만남 카드를 자동으로 나눠 제안합니다.
   - 카드를 눌러 사람·날짜·장소·녹음 연결을 고치고, 맞으면 [이대로 만남 확정]을 누릅니다.
   - 일시·장소·참석자는 접힌 칸 "보고서 정보"에 적습니다.
4. 아래 주 단추 **[보고서 초안 만들기]**를 누릅니다. 이미 초안이 있는데 자료를 더 넣었으면 단추가 **[새 자료 N개를 보고서에 넣기]**로 바뀌고, 기존 내용은 두고 새 자료만 더합니다.
5. **만들기**: 녹음을 글자로 옮기고 → 누가 말했는지 한 번 확인하고 → AI 가 초안을 씁니다.
   - 화자 확인 화면에는 녹음마다 참석자 번호, 발언 수, 대표 발언이 나오고 이름이 미리 채워져 있습니다. 틀린 것만 고치고, 모르면 "모르겠음"을 고릅니다.
   - 다른 만남의 사람 이름이 잘못 붙어 있으면 다시 제안합니다. 한 번 확인한 이름은 다음에 다시 묻지 않습니다.
   - 진행 중에는 다른 일을 해도 됩니다. 실패하면 이유가 나오고, 다시 누르면 이어서 합니다.
6. **결과**: 한글 파일을 열거나 폴더를 엽니다. 고칠 곳은 **한글에서 바로 고치고 저장**하세요. 다음 버전을 만들 때 고친 글자와 문단 자간·장평·굵게 강조를 이어받습니다(줄 일부 글자만 바꾼 자간은 옮기지 못하고 몇 줄인지 알려 줍니다).
   - 한글에서 고쳤으면 위에 [한글에서 고친 내용 불러오기]가 뜹니다. 먼저 누르세요.
   - 오른쪽 "AI 에게 고쳐 달라고 하기"에 '6일 면담은 교수별로 나눠 줘'처럼 적습니다. 바로 바꾸지 않고 수정안을 만들고, [바뀐 곳 보기]로 확인한 뒤 [적용하고 새 한글 버전 만들기]를 누릅니다.
   - "확인할 곳"에 근거가 약한 부분 5개를 보여 줍니다.
   - 원자료(녹음·전사문) 대조, 사실 확인 메모, 이전 버전, 보낸 판 보관 사본은 접힌 칸 "기타 도구"에 있습니다. 보낸 파일은 파일 카드의 [보낸 판으로 보관]으로 그때 모습 그대로 사본을 남깁니다.
   - 이름을 잘못 확인했으면 원자료 화면의 [누가 말했는지 다시 확인]에서 고치고, 보고서 발언자 표기만 고치는 수정안을 만들 수 있습니다.
7. 새 한글 파일은 늘 새 버전(_v2, _v3 …)으로 만들고, 기존 파일은 덮어쓰지 않습니다.

사업·보고서 삭제는 복구 가능한 임시 보관으로 이동합니다. 보관함에서 복원하거나 비울 수 있으며, 영구 삭제 안내를 확인한 뒤 비우세요.

## 5. 양식 바꾸기

[양식] 에서 작성 규칙·번호 형식·제목 앞 빈 줄·표 번호·표지 기관명 등을 바꿉니다.
문단 스타일은 기존 항목도 편집할 수 있고 번호 형식은 기본값에 고정되지 않습니다.
오른쪽 미리보기가 바로 바뀌고, [한글로 정확히 보기] 는 지금 값으로 견본 보고서를 만들어 한글로 엽니다(내 설정·작업은 그대로).
표지·스타일은 [한글에서 템플릿 열기] 로 직접 고칩니다. 고치기 전 원본은 자동으로 백업됩니다.

## 6. 업데이트

프로그램을 열 때 새 버전을 확인해 받습니다. [설정 → 지금 업데이트 확인] 으로 직접 확인할 수도 있습니다.
내가 고친 작성 규칙·표준템플릿과 작업 자료는 업데이트해도 그대로 남습니다
(새 기본값은 옆에 `.새기본값` 파일로 둡니다).

## 문제가 생기면

- [설정 → 환경 점검·설치 열기] 로 빠진 부품을 다시 설치합니다.
- 작업 화면 "진행 상황·기록 자세히"의 마지막 줄을 캡처해 담당자에게 보내 주세요. 이전 실패·중단 기록은 다시 열어도 확인할 수 있습니다.
- 앱을 닫으면 실행 중인 작업도 멈춥니다. 초안이 다른 프로그램에서 바뀌었다는 안내가 나오면 현재 편집 내용을 따로 복사해 보관한 뒤 작업을 다시 여세요.


## 별도 창과 모델 설정

- 메모 칸의 [작성]을 누르면 앱 안에서 긴 메모를 적고 저장할 수 있습니다. 파일 불러오기/붙여넣기도 함께 쓸 수 있습니다.
- 진행 상황은 만들기 화면의 진행 줄에 나타납니다. 자세한 기록은 [진행 상황·기록 자세히]에서 봅니다. 그 창을 닫아도 작업은 계속됩니다.
- 설정에서 사용할 AI와 도구별 모델을 선택하거나 모델 ID를 직접 입력합니다. [CLI 기본값]은 해당 도구의 설정을 사용합니다. 제공되는 모델/이용 가능 여부는 본인 계정과 CLI가 결정합니다.
- 왼쪽 아래 활성 AI 배지에 마우스를 올리면 모델·CLI 버전·로그인 상태를 볼 수 있습니다. 앱 버전과 업데이트 확인 상태는 그 아래에 있습니다.
- 전사 화자 번호는 실제 인원수가 아닙니다. 같은 사람이 여러 번호로 구분될 수 있으며, 이미 확인한 번호는 접어서 표시합니다. 모르는 발언은 예시 문장과 시각을 보고 확인합니다.
- AI 결과 수집에 실패하면 원래 응답/임시 결과 경로를 기록에 남깁니다. 이미 만들어진 결과를 다시 생성하기 전에 보관 경로를 확인하세요.


## 첫 사용 시 알아둘 점

- 왼쪽 아래 Claude/Codex 글자는 현재 설정을 보여 주는 상태 표시입니다. AI를 고르거나 모델·추론 강도를 바꾸려면 [설정]으로 들어갑니다. AI 선택/모델/강도는 같은 카드에서 설정하고 로그인 계정도 확인합니다. 표시된 계정이 다르면 [계정 연결·변경]을 사용합니다.
- 추론 강도는 CLI 기본값 또는 모델이 제공하는 low/medium/high 등의 수준 중에서 고릅니다. 높은 수준은 더 오래 걸릴 수 있습니다. 모델에 따라 선택지가 다릅니다.
- [녹음만 먼저 글자로 옮기기]는 원자료를 먼저 확인하고 싶을 때 쓰는 선택 동작입니다. [보고서 초안 만들기]만 눌러도 자동으로 먼저 진행합니다.
- 내용이 맞으면 [문제 없음·확인 완료]로 검토 상태를 남길 수 있습니다. 이 표시는 미확정 사실을 자동으로 확정하거나 검사 경고를 삭제하지 않습니다.
- .hwp(옛 한글 형식) 자료도 읽습니다. 암호가 걸렸거나 배포용 문서는 읽지 못하니 한글에서 hwpx로 저장해 넣어 주세요.
